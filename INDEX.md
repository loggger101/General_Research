# Master Index — General Research

Every source in this repo, what tier it is, how much of it we can actually use,
and which pipeline table/cell it backs or could replace. `sources.csv` holds the
same data machine-readable (one row per item, with domain dir); each domain also
keeps its own `<domain>/FINDINGS.md` with the prose and per-number comparison
tables.

Legend for **access** (the first word of each `access_status`; README "Access classes" has all six):
- `full_text_hosted` — full PDF committed under `<domain>/full_texts/`, legally redistributable (CC-licensed arXiv preprints, NASA public-domain docs, CC-BY articles); the file and its licence are listed in `full_texts_manifest.csv`.
- `open_not_pulled` — open access but not downloadable from this machine (bot-block) or license needs a user decision; recorded with URL + reason.
- `verified_live_not_pulled`, `open_service`, `public_domain_excerpt_hosted`, `skipped` — read live but not committed; a live database; a public-domain excerpt quoted in FINDINGS; deliberately not hosted.

Findings that contradict an upstream cell are tracked, with their current status, in `revision_candidates.csv`.
